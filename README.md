# Masster — исследовательский проект

Рабочее пространство для подготовки научных статей в рамках PhD-темы:

> **Information Systems and Models for Managing Academic Processes in Distance and
> Traditional Learning Formats at Higher Education Institutions**

Цель — довести до публикации в Scopus-индексируемых журналах серию статей,
опирающихся на собственные эмпирические данные вуза.

## Что здесь есть

| Каталог | Содержимое |
|---|---|
| `docs/` | Анализ исходного отчёта LeapSpace, выбор темы, планы исследований |
| `docs/topics/` | Детальные планы по отдельным темам статей |
| `bibliography/` | 96 источников в BibTeX и JSON, размечены по темам T1–T7 |
| `scripts/` | Извлечение текста из .docx, парсинг ссылок, верификация DOI |
| `data/raw/` | Сырые выгрузки (логи LMS, ответы анкет) — **не коммитится** |
| `data/processed/` | Обезличенные и подготовленные датасеты |
| `analysis/` | Скрипты анализа и результаты |

## Первое, что нужно сделать

Прогнать верификацию ссылок с машины, где есть доступ в интернет:

```bash
python3 scripts/verify_dois.py bibliography/refs.json -o bibliography/refs_verified.json
```

В текущем окружении сеть к `api.crossref.org` закрыта политикой прокси,
поэтому проверка выполнена только выборочно. Подробности и результаты
выборки — в `docs/03-doi-verification.md`.

## Важное предупреждение

Исходный отчёт `Quick_Reference_LeapSpace.docx` **сгенерирован ИИ**. Он
пригоден как карта литературы и как каркас структуры, но:

- ни один абзац оттуда нельзя переносить в статью в исходном виде;
- список источников требует полной проверки перед цитированием;
- научная новизна должна прийти из собственных данных, а не из отчёта.
